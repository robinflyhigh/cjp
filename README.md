# CGP Delhi Player

Netflix-style continuous video player built with Next.js 15.

## Quick start

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

Place video files in `./downloads` (mp4, mkv, webm, mov, m4v, avi). The app scans that folder automatically — no hardcoded filenames.

## Keyboard shortcuts

| Key | Action |
|-----|--------|
| Space | Play / Pause |
| ← | Previous |
| → | Next |
| F | Fullscreen |
| M | Mute |
| ↑ | Volume + |
| ↓ | Volume − |
